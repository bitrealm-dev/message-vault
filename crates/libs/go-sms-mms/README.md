# go-sms-mms

Decode GO SMS Pro MMS PDU bytes for the GO SMS Pro rescue converter.

`go-sms-pro-exporter` uses this crate.

## Build and test

```bash
cargo test -p go-sms-mms
```

Workspace setup: [CONTRIBUTING.md](../../../CONTRIBUTING.md).

## Docs

This crate is a library. Field mapping: https://vault.bitrealm.dev/developer/formats/go-sms-pro/mapping/
