# sbr

Read and write SyncTech SMS Backup & Restore XML (`smses.xml`).

`message-ir-format` and `sms-backup-restore-exporter` use this crate.

## Build and test

```bash
cargo test -p sbr
```

Workspace setup: [CONTRIBUTING.md](../../../CONTRIBUTING.md).

## Docs

This crate is a library. XML output: https://bitrealm.dev/formats/sms-backup-restore-xml/ . Input format: https://bitrealm.dev/formats/sms-backup-restore/input/
