# mail

Build `.eml` files and mboxrd mailboxes from a `ConversationDocument`.

`message-ir-format` uses this crate when the user picks EML or MBOX.

## Build and test

```bash
cargo test -p mail
```

Workspace setup: [CONTRIBUTING.md](../../../CONTRIBUTING.md).
