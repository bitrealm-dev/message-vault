sequenceDiagram
    autonumber
    actor Dev as Developer

    box Local Machine
        participant App as Desktop App (Tauri)
        participant Vite as Vite (port 5173)
        participant Repo as git repo (message-vault)
    end

    box Docker Containers
        participant Vault as Vault (port 8080)
        participant SQLite as SQLite Browser (port 8081)
    end

    box Docker Volumes
        participant AppMount as /app (source mount)
        participant Target as /app/target (Rust cache)
        participant Libs as Cargo registry cache
        participant Data as /app/data (SQLite DB)
    end

    Dev->>Repo: Edits Rust or frontend files
    Note over Repo,AppMount: Repo mounted as /app in Vault container

    Dev->>App: cargo tauri dev
    App->>Vite: Starts Vite dev server
    App->>App: Loads http://localhost:5173

    loop Page open / refresh
        Vite-->>App: Serves web/ assets
    end

    App->>Vault: Login (port 8080)
    Vault-->>App: Auth response

    loop Messages
        App->>Vault: Fetch / send messages
        Vault-->>App: Message data
        Vault->>Data: Persists to SQLite
    end

    Dev->>Vault: Restart container (recompiles)
    Vault->>AppMount: Reads source from /app
    Vault->>Target: Uses cached build artifacts
    Vault->>Libs: Uses cached dependencies
    Vault-->>Dev: Ready (port 8080)

    Dev->>SQLite: Opens browser (port 8081)
    SQLite->>Data: Reads shared database file
    SQLite-->>Dev: Shows database contents
