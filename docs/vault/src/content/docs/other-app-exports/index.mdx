---
title: Rescue messages from other app exports
description: Convert limited exports from GO SMS Pro, iMazing, OpenExtract, or SMS Backup+.
---

import { Aside, Card, CardGrid } from '@astrojs/starlight/components';

Use these importers only when the app export is the only copy you have. They read incomplete or reverse-engineered formats, so the result can contain less information than an export from a supported phone backup.

<CardGrid>
  <Card title="GO SMS Pro">
    Requires a backup directory with `gosms_sys*.xml` and `I_*.pdu` files, plus the owner's phone number. [Read the GO SMS Pro requirements](/other-app-exports/go-sms-pro/).
  </Card>
  <Card title="iMazing">
    Reads iMazing Messages or WhatsApp CSV files, chat folders, or a full device export tree. [Read the iMazing requirements](/other-app-exports/imazing/).
  </Card>
  <Card title="OpenExtract">
    Reads `all_conversations.csv` or `conversation_*.csv`; a contacts file is strongly recommended. [Read the OpenExtract requirements](/other-app-exports/openextract/).
  </Card>
  <Card title="SMS Backup+">
    Reads offline `.eml` files, not a live email account. Owner identity is needed to identify sent messages reliably. [Read the SMS Backup+ requirements](/other-app-exports/sms-backup-plus/).
  </Card>
</CardGrid>

<Aside type="caution" title="Prefer a supported source when one is available">
  Prefer SMS Backup & Restore XML over GO SMS Pro or SMS Backup+, an iPhone backup or `chat.db` over iMazing Messages CSV, and a native WhatsApp database or backup over iMazing WhatsApp CSV.
</Aside>
