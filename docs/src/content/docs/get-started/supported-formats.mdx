Message Vault has two format questions: where the messages come from, and what files you want written (or uploaded) afterward.

## Source formats (what you start with)

Use these guides when you are extracting from a phone backup or an existing app export.

<CardGrid>
  <Card title="Apple Messages">
    Mac `chat.db` or an iPhone backup, including encrypted backups when you know the password. [Apple Messages](/apple/text-messages/).
  </Card>
  <Card title="Apple WhatsApp">
    WhatsApp data inside an iPhone backup, extracted with the bundled helper. [WhatsApp on Apple](/apple/whatsapp/).
  </Card>
  <Card title="Android text messages">
    SMS Backup & Restore XML for SMS/MMS. [Android text messages](/android/text-messages/).
  </Card>
  <Card title="Android WhatsApp">
    A WhatsApp database or encrypted backup plus its key. [WhatsApp on Android](/android/whatsapp/).
  </Card>
  <Card title="Other app exports">
    Rescue paths for GO SMS Pro, iMazing CSV, OpenExtract, and SMS Backup+. These source formats can omit details. [Other app exports](/other-app-exports/).
  </Card>
</CardGrid>

<Aside type="note" title="Guided Import Messages">
  The guided **Home → Vault Credentials → Import Messages** flow extracts and uploads Apple Messages as JSONL from an **iPhone backup** or a **macOS `chat.db`**. Use Extract Messages plus the source guides above for WhatsApp, Android, and rescue formats, then [import the JSONL folder to Message Vault](/work-with-exports/import-to-vault/) when you are ready.
</Aside>

## Output formats (what Message Vault writes)

Extract Messages always writes **JSONL** first. Use the Format tab or the output-format guide when you need another packaging:

- [Choose an output format](/work-with-exports/output-formats/) — CSV, JSON, JSONL, EML, MBOX, Android XML
- [Convert the format](/work-with-exports/convert-format/) — turn an existing Message Vault folder into another format
- [Export structure](/understand-output/export-structure/) — how folders and attachment paths are laid out

JSONL is also the format Message Vault import expects when you [upload to the vault](/work-with-exports/import-to-vault/).
