## How it works

```text
1. Export     Phone backup → message-ir JSONL + attachments/
              (Message Exporters / message-exporter)

2. Import     Push (projects to vault JSONL) or ingest into the vault

3. Browse     Open the website on your computer
```

Turning a phone backup into message-ir JSONL is a separate project:
[Message Exporters](https://bitrealm-dev.github.io/message-exporters/).
This site covers the vault: storage, import, and the browser UI.

Your messages stay in a SQLite database on a machine you control. They are not
uploaded to a cloud service by this project.

<Aside type="tip" title="Two processes for remote import">
  Browsing only needs the Next.js web UI. Remote import also needs the Rust
  import API (`cargo run --release -- serve`). Same-machine `ingest` does not
  require `serve`.
</Aside>
