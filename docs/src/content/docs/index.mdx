## How it works

```text
1. Try it     Run the vault, sign in as demo in the browser
              (sample conversations — no phone backup yet)

2. Your data  Create an account on that same vault, prepare a backup,
              import with the desktop app

3. Browse     Search and read threads on the website you control
```

Your messages stay in a SQLite database on a machine you control. They are not uploaded to a cloud service by this project. The vault login is local — not a Bitrealm cloud account.

Already sure you want your own data? Skip the sample login and go to [Use your own messages](/get-started/your-own-messages/).

<Aside title="Supported paths and limited rescue imports">
  The supported paths are Apple Messages from chat.db or an iPhone backup, Android SMS/MMS from SMS Backup & Restore XML, and WhatsApp through wtsexporter. GO SMS Pro, iMazing, OpenExtract, and SMS Backup+ are rescue imports for files you already have. [Rescue imports](/how-to/rescue-imports/).
</Aside>
