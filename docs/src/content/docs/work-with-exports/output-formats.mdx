---
title: Choose an output format
description: Compare CSV, JSON, JSON Lines, EML, MBOX, and Android XML.
---

import { Aside, Tabs, TabItem } from '@astrojs/starlight/components';

Choose the format that the next program needs. JSON is the default because it keeps the shared message structure in a form that is easy to inspect and convert later.

<Tabs>
  <TabItem label="CSV">
    Writes one `.csv` file per conversation. Use it for spreadsheets, filtering, scripts, and systems that accept rows and columns.

    Copied media goes in `attachments/`, and rows contain relative paths. See [Understand CSV columns](/understand-output/csv-columns/).
  </TabItem>
  <TabItem label="JSON">
    Writes one indented `.json` document per conversation. Use it as the default archive when you may convert formats later or want one structured document for each chat.

    Copied media goes in `attachments/`; the JSON does not contain the media bytes.
  </TabItem>
  <TabItem label="JSONL">
    Writes one `.jsonl` file per conversation, with a conversation header followed by one message per line. Use JSON Lines when a script should stream or filter records without loading a whole conversation.

    Copied media goes in `attachments/`.
  </TabItem>
  <TabItem label="EML">
    Writes one folder per conversation and one `.eml` file per message. Use it when a mail program imports individual email files.

    Media is embedded as MIME attachments. There is no sidecar `attachments/` folder.
  </TabItem>
  <TabItem label="MBOX">
    Writes one `.mbox` mailbox per conversation. Use it when a mail program prefers one mailbox file instead of individual EML files.

    Media is embedded as MIME attachments. There is no sidecar `attachments/` folder.
  </TabItem>
  <TabItem label="Android XML">
    Writes one `smses.xml` in the SyncTech SMS Backup & Restore format. Use it when an Android workflow needs the format that app reads.

    Media is embedded as base64 in the XML. Apple-only fields are dropped because the format cannot represent them.
  </TabItem>
</Tabs>

<Aside type="tip" title="You can choose the final format on the first run">
  Extract Messages always writes JSONL. Use the Format tab after you already have a Message Vault output folder and want another format.
</Aside>
