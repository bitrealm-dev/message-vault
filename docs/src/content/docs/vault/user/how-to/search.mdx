Use the search box in the app header. Open the advanced search form (chevron next to the box) when you want structured fields instead of typing operators by hand.

Advanced search has two modes:

- **Messages** — *what was said?* Full-text search across message bodies (operators for from/to/with, attachments, dates, and sources). Results are usually one row per conversation (match count + snippet).
- **Contacts** — *who do I know?* Filters the contact list by name, phone, and related fields. It does not search message text.

Typing plain words in the search box runs a **Messages** search. Add operators to narrow it:

<TypedQuery query='from:me to:"Jane Doe" avocado after:2020' />

<TypedQuery query="last-contact:<2022" note="on Contacts" />

## Opening a message result

Clicking a message result opens the conversation so you can read the matching thread. Use in-conversation find when you need to step through highlights inside a long chat.

Save a query under **Saved searches** in the sidebar — [Saved searches](/vault/user/how-to/saved-searches/).

## Query operators

The search box accepts operators (the advanced form composes many of these for you). The tiles show where each one applies: <ListTiles on="C" /> Contacts search, <ListTiles on="V" /> filters whole conversations, <ListTiles on="M" /> Messages search.

| Operator | Meaning | Applies to |
|----------|---------|------------|
| `"exact phrase"` | Match the phrase | <ListTiles on="M" /> |
| `-word` / `NOT word` | Exclude messages containing the word | <ListTiles on="M" /> |
| `word*` | Prefix match (e.g. `avoc*` matches avocado) | <ListTiles on="M" /> |
| `OR` / `AND` / `(…)` | Boolean free-text matching (AND is default between words) | <ListTiles on="M" /> |
| `from:me` / `from:name` | Sent by you, or by this sender | <ListTiles on="M" /> |
| `to:me` / `to:name` | Received by you, or sent by you to this person | <ListTiles on="M" /> |
| `with:name` | Conversation involves this person (any role) | <ListTiles on="M" /> |
| `first:text` / `last:text` | Contact first / last name (Contacts mode, or Messages with-person) | <ListTiles on="CM" /> |
| `is:nofirst` / `is:nolast` | Empty first / last name | <ListTiles on="C" /> |
| `phone:text` | Phone or email handle | <ListTiles on="C" /> |
| `subject:text` | Subject contains text | <ListTiles on="M" /> |
| `text:terms` | Body only (bare terms also search subject and attachment names) | <ListTiles on="M" /> |
| `after:2020` / `before:2021-06-01` | Date bounds (local calendar; also `7d` / `1w` / `1m` / `1y`) | <ListTiles on="M" /> |
| `is:direct` / `is:group` | Only 1-1 or only group conversations | <ListTiles on="VM" /> |
| `source:imessage` | Only one import source | <ListTiles on="M" /> |
| `has:attachment` / `has:noattachment` | With or without attachments | <ListTiles on="M" /> |
| `filename:text` | Attachment filename contains text | <ListTiles on="M" /> |
| `filetype:image` | Attachment category (`image`, `video`, `audio`, `document`, `contact`, `other`; `pdf` → document) | <ListTiles on="M" /> |
| `larger:1M` / `smaller:500k` | Attachment size bounds (`K` / `M` / `G`, or raw bytes) | <ListTiles on="M" /> |
| `group:none` | One result row per matching message (default is per conversation) | <ListTiles on="M" /> |
| `context:2` | Include N surrounding messages when showing/opening a hit | <ListTiles on="M" /> |
| `sort:date-asc` / `sort:relevance` | Oldest first, or FTS best-match (default newest first) | <ListTiles on="M" /> |
| `in:title` | Restrict to a conversation by title or handle | <ListTiles on="VM" /> |
| `people:Family` | Threads that involve at least one contact in that contact group. Aliases: `within:`, `label:` | <ListTiles on="VM" /> |
| `-people:Family` | Hide threads that involve that contact group | <ListTiles on="VM" /> |
| `tag:Holiday` | Threads that have this message tag. Quote names with spaces: `tag:"Work Friends"` | <ListTiles on="VM" /> |
| `-tag:Holiday` | Hide threads that have this message tag | <ListTiles on="VM" /> |
| `tag:none` | Threads with no message tags | <ListTiles on="VM" /> |
| `within:Family` | Same as `people:` (older spelling) | <ListTiles on="VM" /> |
| `search:contacts` | Switch to Contacts search | <ListTiles on="CM" /> |
| `handle:text` | (Contacts) combined name or number contains text | <ListTiles on="C" /> |
| `first-contact:>=2019` / `last-contact:<2022` | (Contacts) first / last message dates | <ListTiles on="C" /> |
| `group-count:>5` / `message-count:>100` | (Contacts) group / direct message counts | <ListTiles on="C" /> |
