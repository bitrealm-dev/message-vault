title: Trash
description: Soft-deleted items in the sidebar Trash view.
---

The sidebar includes a **Trash** view for soft-deleted conversations and related items.

The unified website shows **Trash** in the navigation. Soft-delete **restore** and **empty trash** API routes are not part of the current vault server (`/v1/*`). Treat Trash as a placeholder until those endpoints ship — do not rely on restore, permanent delete, or undo snackbars.

For day-to-day browsing, use **Conversations** and **Contacts**. To remove all message content for an account, use **Settings → Account** danger-zone actions (delete messages).

See [Settings](/vault/user/how-to/settings/).
