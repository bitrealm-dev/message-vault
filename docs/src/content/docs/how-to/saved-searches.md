---
title: Saved searches
description: Store a search query under Saved Groups and run it again from the sidebar.
---

**Saved groups** under the sidebar store search queries you reuse. They are not a separate list of group chats — group conversations live in **Conversations**.

1. Run a [search](/how-to/search/)
2. Create a saved group with **+ New**
3. Click the saved name later to run that query again
