# Clap CLI Pages and Rustdoc on Starlight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace hand-written CLI man pages with clap-generated Starlight markdown, and publish workspace rustdoc HTML at `/vault/developer/rustdoc/` on bitrealm.io.

**Architecture:** Each documented tool exports `pub fn clap_command() -> clap::Command`. A small `dump-cli-docs` crate wraps clap-markdown with Starlight frontmatter and writes committed files. Docs CI on `main` runs `cargo doc --workspace --no-deps --exclude message-vault-io-gui`, copies HTML into `docs/public/vault/developer/rustdoc/`, then builds Starlight. HTTP OpenAPI stays on the existing utoipa path.

**Tech Stack:** clap 4.6 derive + `CommandFactory`, clap-markdown 0.1, Astro 7 / Starlight 0.41, GitHub Actions (Node 24 + Rust stable)

## Global Constraints

- Do not change HTTP OpenAPI / utoipa / `starlight-openapi` behavior.
- Clap markdown is committed. Rustdoc HTML is not committed.
- `dump-cli-docs` does not read `config.toml`, bind a port, or open SQLite.
- Document only the eleven commands already on the Developer site (seven exporters + `message-reexporter` + `vault-push` + `vault-pull` + `message-vault-server`). No new pages for `contacts_validate`, `demo-seed`, or `imazing_obfuscate`.
- Keep the hand-written index at `docs/src/content/docs/vault/developer/reference/cli/index.md`.
- Each generated page uses today’s Starlight `title` and `description` (table in Task 1). Flag body comes from clap-markdown.
- Generated pages include `editUrl: false` and a “generated by dump-cli-docs; do not edit” HTML comment.
- `pub fn clap_command() -> clap::Command` is `Cli::command()` from clap `CommandFactory`.
- Split `message-vault-server` into `lib.rs` + thin `main.rs`. CLI behavior does not change.
- `cargo doc --workspace --no-deps --exclude message-vault-io-gui`. No `--document-private-items`. No `RUSTDOCFLAGS=-D warnings` in this work.
- Docs CI runs on push to `main` only (not PRs). Path filters include `docs/**`, `crates/**`, `Cargo.toml`, `Cargo.lock`, and the workflow file. Timeout 20 minutes. Always rebuild rustdoc on those deploys.
- Non-flag prose from `server-cli.md` (process-assets counters, reset-demo summary groups, dump-openapi usage) moves to the CLI index before the man page is deleted.
- Docs copy: short sentences, no “we” / “us” / “our”. Starlight `title=""` on code fences in authored pages.
- Existing crate tests must keep passing. Product `/v1` HTTP behavior must not change.

pub fn render_page(spec: &PageSpec, command: &Command) -> String {
    let body = clap_markdown::help_markdown_command(command);
    format!(
        "---\ntitle: {title}\ndescription: {description}\neditUrl: false\n---\n\n<!-- generated by dump-cli-docs; do not edit -->\n\n{body}",
        title = yaml_quoted(spec.title),
        description = yaml_quoted(spec.description),
        body = body.trim(),

}

fn yaml_quoted(s: &str) -> String {
    format!("\"{}\"", s.replace('\\', "\\\\").replace('"', "\\\""))

```rust
pub fn command_for(id: &str) -> anyhow::Result<clap::Command> {
    Ok(match id {
        "imessage-ir-exporter" => imessage_ir_exporter::clap_command(),
        "sms-backup-restore-exporter" => sms_backup_restore_exporter::clap_command(),
        "whatsapp-exporter" => whatsapp_exporter::clap_command(),
        "go-sms-pro-exporter" => go_sms_pro_exporter::clap_command(),
        "imazing-exporter" => imazing_exporter::clap_command(),
        "openextract-exporter" => openextract_exporter::clap_command(),
        "sms-backup-plus-exporter" => sms_backup_plus_exporter::clap_command(),
        "message-reexporter" => message_reexport::clap_command(),
        "vault-push" => vault_push::clap_command(),
        "vault-pull" => vault_pull::clap_command(),
        "message-vault-server" => message_vault_server::clap_command(),
        other => anyhow::bail!("unknown command id {other}"),
    })
}

pub fn page_markdown(id: &str) -> anyhow::Result<String> {
    let spec = PAGE_SPECS
        .iter()
        .find(|s| s.id == id)
        .ok_or_else(|| anyhow::anyhow!("unknown page id {id}"))?;
    Ok(render_page(spec, &command_for(id)?))
}

pub fn write_pages(output_dir: &std::path::Path) -> anyhow::Result<()> {
    for spec in PAGE_SPECS {
        let path = output_dir.join(spec.rel_path);
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        std::fs::write(&path, page_markdown(spec.id)?)?;
    }
    Ok(())
}
```
